# Bevel feedback

Bug reports and feature requests for Bevel, an add-on for creating and editing geometry in Godot's 3D editor.

- [Report a bug](https://github.com/voidref-org/bevel-feedback/issues/new?template=bug_report.yml) — something isn't working as expected.
- [Request a feature](https://github.com/voidref-org/bevel-feedback/issues/new?template=feature_request.yml) — suggest something new or an improvement.

You'll need a GitHub account to submit an issue.

## Before you post

[Search existing issues](https://github.com/voidref-org/bevel-feedback/issues) to see whether someone has already reported the same thing. If they have, add a 👍 reaction or a comment with any extra details that could help.

Please submit one bug or idea per issue and give it a short, descriptive title. For example: “Extruding a face leaves a gap in the mesh” or “Add a shortcut to reset texture scale.”

## Reporting a bug

Describe what you were doing, what you expected to happen, and what actually happened. Include the steps to reproduce the problem, your Godot and Bevel versions, and your operating system. For export problems, include the export platform too.

Screenshots, a short recording, or relevant errors from Godot's Output or Debugger panels can help. You can drag files into the form's text boxes. If you can't reproduce the problem every time, share what you remember anyway.

## Suggesting a feature

Describe what you're trying to do and what gets in your way. Explain how your idea would help, and mention any workaround you use today.

For tool instructions, see the [Bevel documentation](https://bevel.voidref.dev/).

## Following up

Keep an eye on your issue in case someone asks for more information. If you find a workaround or the problem goes away, add a comment so others can benefit. Suggestions are welcome, but submitting one doesn't guarantee it will be built or receive a response by a particular date.
